# Forms

Each file here is one form, written as ordinary information. They are checked
automatically on every save: a broken form is refused here, on a laptop, rather
than discovered in a village.

**To add or change a form**

1. Copy an existing file and edit it.
2. Save. The automatic check will tell you if anything is wrong, in plain words.
3. To put it on people's phones, run the **Publish a form** action on GitHub and
   give it the file name.

**Publishing is printing.** You can publish edition 4, but you can never change
the copies already handed out. Every answer records which edition produced it,
so an answer given three years ago still means exactly what it meant on the day.
A typo fix is a new edition, and that is deliberate.

The builder screen — where a supervisor assembles a form from menus — is not
built yet. It was deliberately left out, because these files give the same
refusals at the same moment with no screen to build, and there is not yet a
supervisor other than the owner who needs one.
